🎵 Music Player

A web-based music player built with HTML, CSS, and JavaScript, featuring playlist management, search, category filtering, and full playback controls.

✨ Features
Play / Pause / Next / Previous — standard playback controls
Volume control — adjustable slider synced to the audio element
Progress bar — shows current playback position, click to seek
Search — filter songs instantly by title or artist
Category filters — browse by genre (Lo-fi, Rock, Electronic, Jazz, etc.)
Playlists — create custom playlists and add/remove songs from them
Compact view toggle — collapse the header and side panels into a minimized layout showing only the logo and key icons
🛠️ Built With
HTML5 — structure (index.html)
CSS3 — styling and layout (style.css)
JavaScript (Vanilla) — playback logic, search/filter, playlist management (script.js)
